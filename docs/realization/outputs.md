# Assessment Outputs

The framework produces defined outputs that allow assessment results to be translated into organizational action. It produces more than an assessment report.

## The six outputs

| Output | Content |
|--------|---------|
| Modernization Assessment Profile | Current condition, dimension profiles, strengths, weaknesses, and evidence coverage |
| Modernization Findings | Observed deficiencies, risks, constraints, strategic gaps, and unmet needs |
| Modernization Opportunities | Areas of opportunity, rationale, significance, and expected value |
| Architecture Implication Profiles | Domain-specific interpretation of modernization needs and target architecture implications |
| Modernization Priorities | Prioritized opportunities based on strategic importance, urgency, value, exposure, and dependencies |
| Modernization Roadmap | Sequenced interventions, decisions, capability changes, initiatives, and target-state progression |

## The questions the assessment must answer

1. Where is modernization needed?
2. Why is it needed?
3. What is driving it?
4. How significant is the need?
5. What is the consequence of not modernizing?
6. What value could modernization produce?
7. Which architecture domains are affected?
8. What capabilities need to be introduced, improved, transformed, or retired?
9. What architectural decisions are required?
10. What is the target state?
11. What should be modernized first?
12. How should modernization be realized?
13. How do we establish whether modernization has actually delivered its intended value?

## Traceability requirement

Every element of every output traces back through the chain: criterion result, evidence, finding, opportunity, objective, intervention, initiative, outcome, value realization. An output statement that cannot be traced to assessment evidence is an assertion, not an assessment finding.
