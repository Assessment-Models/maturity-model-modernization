# AMAF criterion catalog identity baseline (machine-checked).
#
# Checked by framework/validate_catalog.py against the catalog on every run
# and in CI (.github/workflows/framework-ci.yml). Criterion IDs are stable
# (CONTRIBUTING.md): an ID is never reworded into a new ID, and an existing
# ID is never reassigned to a different criterion. Adding, removing or
# renaming an ID (or a dimension or subdimension) is a deliberate change:
# update this baseline in the same change-set, and the framework change
# review process (docs/governance/versioning.md) treats the baseline edit
# as the visible record of the identity change.
#
# Format: one record per line, '<kind> <id> <name>', kinds are dimension,
# subdimension, criterion. Names are part of the stability contract.
#
